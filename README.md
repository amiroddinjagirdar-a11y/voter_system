# Voter System

## Project Overview
The Voter System is a web-based application designed to manage voter information and support the voting process.

## Features
- Voter information management
- User-friendly interface
- Database management
- Voter record storage

## Technologies Used
- PHP
- MySQL
- HTML
- CSS
- JavaScript

## How to Run
1. Install XAMPP.
2. Copy the project folder into `C:\xampp\htdocs`.
3. Start Apache and MySQL.
4. Import the project database into phpMyAdmin, if required.
5. Open the project in your browser using localhost.
